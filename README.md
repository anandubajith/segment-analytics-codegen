# segment-analytics-codegen

## Usage

- Create `events.yaml` file
- Install `segment-analytics-codegen`
```sh
go get github.com/anandubajith/segment-analytics-codegen
```
- Generate code
```sh
go run github.com/anandubajith/segment-analytics-codegen events.yaml
```
